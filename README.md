# Rose Villa · Housewarming Invitation (The Ahmed Family)

A premium, interactive digital housewarming invitation website built for Ahvaan For You (`ahvaanforyou.com`).

- **Family:** The Ahmed Family (Imran & Ayesha)
- **Occasion:** Housewarming Ceremony & House Blessing
- **Venue:** Rose Villa, Indiranagar, Bengaluru
- **Date:** Sunday, 6 December 2026

## Features

- **Interactive Door Reveal Animation**
- **Live Countdown Timer**
- **Chronological Ceremony Schedule**
- **Home Tour Editorial Gallery**
- **Interactive Venue Directions & Google Maps link**
- **RSVP Form with attendance & dietary tracking**
- **Interactive Wishes & Guestbook Board**
- **Add-to-Calendar 1-click integration**

## Development

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
npx vercel --prod
```
